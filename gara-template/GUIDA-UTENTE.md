# ✨ COSA PUOI FARE

## 📝 Gestione Iscrizioni

### Per gli atleti
- **Iscrizione online** facile e veloce
- Scelta delle **discipline** con calcolo automatico del costo
- **Pagamento flessibile**: carta di credito, bonifico o contanti in loco
- **Conferma via email** istantanea
- **Verifica stato iscrizione** in qualsiasi momento

### Per te (organizzatore)
- **Pannello admin** completo per gestire tutte le iscrizioni
- **Conferma/annulla** iscrizioni con un click
- **Verifica ricevute** bonifico caricate dagli atleti
- **Export Excel** di tutti gli iscritti
- **Invio email** collettive a tutti i partecipanti
- **Statistiche** in tempo reale (iscritti, incasso, discipline)

Il sistema invia automaticamente:

- ⚠️ **Solleciti** per pagamenti in sospeso

## 📊 Pannello Admin

Un'unica interfaccia per gestire tutto:

### Tab Iscritti
- Lista completa con filtri e ricerca
- Stato pagamento (sospesa/confermata/verifica)
- Dettagli iscrizione espandibili
- Azioni rapide (conferma, annulla, sollecita)
- Note admin per ogni iscritto

### Tab Prove Pista
- Riepilogo prenotazioni per giorno/orario
- Gestione slot disponibili
- Verifica pagamenti prove

### Tab Merchandising
- Ordini in arrivo
- Stato preparazione
- Quantità per taglia

### Tab Risultati
- Upload PDF classifiche
- Pubblicazione istantanea
- Invio notifiche push

### Tab Statistiche
- Iscritti totali e per disciplina
- Incasso previsto ed effettivo
- Grafici e report

# ❓ FAQ

**D: Posso personalizzare i colori?**
R: Sì, tutto è configurabile tramite il file config.json

**D: Quante iscrizioni può gestire?**
R: Testato con oltre 200 iscritti, nessun limite tecnico

**D: Funziona senza connessione?**
R: No, richiede connessione internet

**D: Posso usarlo per più gare?**
R: Sì, ogni gara ha la sua istanza separata

**D: I dati sono sicuri?**
R: Sì, database PostgreSQL con backup, HTTPS obbligatorio
